第二章：开发环境搭建

Java 教程 · 2026-04-26 · 13 分钟阅读

1. JDK 25 的下载与安装

1.1 OpenJDK、Oracle JDK 和发行版的选择

Java Development Kit（JDK）是用于开发 Java 应用程序的软件开发工具包。目前市面上主要有两种 JDK 来源：

  • Oracle JDK：由 Oracle 官方维护与发布，是最正统的 Java 开发工具包。自 Java 17 起，Oracle JDK 采用免费商业许可（Oracle No-Fee Terms and Conditions），允许在生产环境中免费使用。
  • OpenJDK：Java 的开源参考实现，是 Oracle JDK 的上游项目。Oracle 和众多社区参与者共同维护 OpenJDK。

注意：无论是 Oracle JDK 还是 OpenJDK，两者在功能和语法支持上完全一致。Oracle JDK 基于 OpenJDK 构建，仅增加了少许商业特性（如 Flight Recorder 的某些高级功能），对学习与日常开发没有影响。

除 Oracle 官方版本外，还有许多基于 OpenJDK 构建的第三方发行版，它们通过了 Java 技术兼容性工具包（TCK）认证，提供免费的长期安全更新：

  • Eclipse Temurin：由 Eclipse 基金会维护，社区活跃，免费开源，是当前最受欢迎的发行版之一。
  • Amazon Corretto：亚马逊提供，免费长期支持，针对 AWS 环境优化。
  • Azul Zulu：Azul 公司提供，免费社区版，也提供商业支持。
  • Red Hat build of OpenJDK：红帽提供，面向企业用户。

本教程推荐使用 Eclipse Temurin 25（LTS），因为它是目前最新的长期支持版本，免费、跨平台，并且提供定期的安全更新。Eclipse Temurin 25 已于 2025 年 9 月 30 日发布，目前提供 Windows、macOS 和 Linux 各主要平台的安装包。

补充说明：截至 2026 年 4 月，JDK 26 已发布，但它是一个非 LTS 版本，只提供半年的更新支持。对于学习来说，选择具有长期支持的 Temurin 25 更稳妥。

1.2 Windows / macOS / Linux 下的安装步骤

Windows 安装步骤

  1. 访问 Adoptium 官方网站，在首页点击 “Download Temurin” 按钮，网站会自动检测你的操作系统并推荐对应的安装包。
  2. 也可以手动选择：Temurin 25 (LTS) → Windows → x64 → .msi 安装包，下载完成后双击运行。
  3. 安装向导启动后，点击 “Next”，接受许可协议。
  4. 选择安装路径，建议使用默认路径（如 C:\Program Files\Eclipse Adoptium\jdk-25.0.X-hotspot\）。
  5. 在出现 Custom Setup 界面时，务必确保 “Set JAVA_HOME variable” 选项设置为 “整个功能将安装在本地硬盘上”，这会将 JDK 路径自动写入系统环境变量。
  6. 点击 “Install”，等待安装完成。
  7. 安装完成后，建议重启计算机，以确保环境变量在整个系统中生效。

macOS 安装步骤

  1. 访问 Adoptium 官方网站，网站会自动识别你的 macOS 和芯片架构。
  2. 也可手动选择：Temurin 25 (LTS) → macOS → aarch64（Apple M 系列芯片）或 x64（Intel 芯片）→ .pkg。
  3. 双击 .pkg 文件，按照安装向导提示：继续 → 安装，可能需要输入管理员密码。
  4. 如果你已安装 Homebrew，也可以在终端中执行以下命令快速安装：
brew install --cask temurin@25

Homebrew 会自动将 JDK 安装到标准的 macOS Java 目录 /Library/Java/JavaVirtualMachines/temurin-25.jdk/。

Linux 安装步骤

  • Ubuntu / Debian（22.04/24.04 版本已测试通过）
sudo apt update
sudo apt install -y temurin-25-jdk
  • Fedora / RHEL
sudo dnf install java-25-openjdk-devel

也可以从 Adoptium 网站 下载 .tar.gz 包自行解压到 /usr/local/ 目录。

2. 环境变量配置

2.1 什么是环境变量？

环境变量是操作系统用来存储系统设置和配置信息的变量。对 Java 开发来说，最重要的两个变量是：

  • JAVA_HOME：指向 JDK 的安装根目录。许多 Java 工具（如 Maven、Gradle、Tomcat、各种 IDE）都依赖这个变量来定位 JDK。
  • PATH：操作系统的可执行文件搜索路径。将 JDK 的 bin 目录添加到 PATH 后，就可以在任意目录下直接使用 java、javac、jshell 等命令。

2.2 Windows 配置

如果在安装时已经勾选了 “Set JAVA_HOME variable”，通常无需手动配置。如需手动配置或检查：

  1. 右键点击 “此电脑” 或 “计算机”→ 属性 → 高级系统设置 → 环境变量。

  2. 在 “系统变量” 区域，点击 “新建”：

    • 变量名：JAVA_HOME
    • 变量值：JDK 的安装路径，例如 C:\Program Files\Eclipse Adoptium\jdk-25.0.1.8-hotspot\

  3. 在 “系统变量” 中找到并选中 Path 变量，点击 “编辑”，新增一行：

%JAVA_HOME%\bin

并将这一行上移到列表顶部，确保系统优先使用此版本。

2.3 macOS 配置

macOS 通常在安装 JDK 后自动配置好 PATH。如需手动配置，编辑 ~/.zshrc 文件（如果使用 bash 则编辑 ~/.bash_profile），添加：

export JAVA_HOME=$(/usr/libexec/java_home -v 25)
export PATH=$JAVA_HOME/bin:$PATH

保存后执行 source ~/.zshrc 使配置生效。

2.4 Linux 配置

编辑 ~/.bashrc 或 ~/.profile 文件，添加：

export JAVA_HOME=/usr/lib/jvm/temurin-25-jdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

保存后执行 source ~/.bashrc 使配置生效。

补充：如果你在终端中执行 java -version 时输出的版本不是 25，可能是系统中存在多个 Java 版本。Windows 用户可通过调整 PATH 中 %JAVA_HOME%\bin 的位置（移到最前面）来解决；macOS / Linux 用户可通过 export JAVA_HOME 命令指定默认版本。

3. 命令行体验 Java

3.1 java -version 验证安装

安装和配置完成后，打开终端（Windows 下为命令提示符或 PowerShell），输入以下命令验证安装是否成功：

java -version

正常输出示例（Windows 上）：

openjdk version "25.0.1" 2025-11-04 LTS
OpenJDK Runtime Environment Temurin-25.0.1+8 (build 25.0.1+8-LTS)
OpenJDK 64-Bit Server VM Temurin-25.0.1+8 (build 25.0.1+8-LTS, mixed mode, sharing)

再验证编译器版本：

javac -version

正常输出示例：

javac 25.0.1

如果以上两个命令均正常输出版本信息，说明 JDK 安装和配置完全成功。如果出现 “命令未找到” 或 “不是内部或外部命令” 等错误提示，请返回检查环境变量配置是否正确。

3.2 jshell 交互式编程工具

从 JDK 9 开始，Java 引入了 JShell 工具。JShell 是一个 REPL（Read-Eval-Print Loop，即 “读取 - 求值 - 输出” 循环）交互式编程环境。你可以在不创建类、不写 main 方法的情况下，直接输入 Java 代码并立即看到运行结果，非常适合学习和快速实验。

在终端中输入 jshell 启动：

jshell

终端提示符会变为 jshell>，现在可以直接输入 Java 语句：

jshell> System.out.println("Hello, JShell!")
Hello, JShell!

jshell> int x = 10 + 20
x ==> 30

jshell> Math.sqrt(25)
$3 ==> 5.0

jshell> "Hello".toUpperCase()
$4 ==> "HELLO"

JShell 常用命令：

  • /help：查看帮助信息
  • /exit：退出 JShell
  • /list：列出所有已输入的代码片段
  • /vars：列出所有已定义的变量
  • /methods：列出所有已定义的方法

提示：本教程前几章的许多语法示例，都可以直接在 JShell 中尝试，无需每次创建完整的类和 main 方法。遇到不确定的代码片段时，可以随时打开 JShell 快速验证。

3.3 使用 javac 和 java 命令

Java 程序的开发流程分为三步：编写源文件 → 编译 → 运行。

编写              编译              运行
┌─────────┐     ┌─────────┐     ┌──────────┐
│  .java  │────▶│  .class │────▶│ JVM 执行  │
│  源文件  │     │  字节码  │     │          │
└─────────┘     └─────────┘     └──────────┘
  • javac（Java Compiler）：Java 编译器，将 .java 源文件编译为 JVM 能识别的 .class 字节码文件。
  • java（Java Launcher）：Java 启动器，启动 JVM 加载并执行 .class 字节码。

传统方式（理解面向对象结构）

打开任意文本编辑器（如记事本、VS Code），创建一个文件，命名为 HelloWorld.java（注意：文件名必须与类名完全一致，包括大小写）。

输入以下代码：

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

代码解析：

  • public class HelloWorld：定义了一个公开的类，类名是 HelloWorld。
  • public static void main(String[] args)：Java 程序的入口方法（main 方法），JVM 从这里开始执行程序。public 表示该方法可以被外部访问，static 表示它是静态方法，void 表示没有返回值，String[] args 是命令行参数。
  • System.out.println("Hello, World!")：向控制台输出一行文本，println 表示输出后自动换行。

保存文件后，在该文件所在目录打开终端，依次执行：

编译：

javac HelloWorld.java

编译成功后，当前目录会生成 HelloWorld.class 文件。如果命令没有任何输出提示，说明代码编译通过。

运行：

java HelloWorld

注意：这里写的是 java HelloWorld，不是 java HelloWorld.class。JVM 会根据类名自动查找对应的 .class 文件。

你应该会在控制台看到输出：

Hello, World!

新式简化方式（JDK 25 新特性）

JDK 25 引入了 JEP 512：紧凑源文件与实例 main 方法 特性，允许初学者编写更简洁的程序，无需显式声明 public class 和 public static void main(String[] args)。

创建一个名为 Hello25.java 的文件，内容如下：

void main() {
    System.out.println("Hello, Java 25!");
}

然后在终端中直接运行：

java Hello25.java

JDK 25 会自动编译并执行这个源文件，输出：

Hello, Java 25!

学习建议：虽然 JDK 25 提供了更简洁的写法，但建议初学者先掌握传统写法（public class + public static void main），因为：

  1. 传统写法能帮助你理解类、对象、方法等面向对象的核心概念。
  2. 绝大多数书籍、文档和遗留项目仍使用传统写法。
  3. 掌握传统写法后，再学简化写法会非常轻松。

4. 常见编译运行错误速查表

错误信息 原因 解决方法
'javac' 不是内部或外部命令 JDK 的 bin 目录未添加到 PATH 检查环境变量配置是否正确
错误: 找不到文件: HelloWorld.java 当前目录下没有该文件 检查文件名是否一致，确认当前目录是否正确
错误: 类 HelloWorld 是公共的 文件名与类名不一致 确保文件名与 public class 后的类名完全一致（含大小写）
找不到或无法加载主类 HelloWorld 运行时没有找到类文件 确认是否已成功编译，运行命令不带 .class 后缀
HelloWorld.java:1: 错误: 需要 ';' 语法错误，缺少分号 检查每行语句末尾是否有分号

5. 本章小结

完成本章的学习后，你已经：

  • ✅ 了解了 Oracle JDK 与 OpenJDK 的区别，并选择安装了 Eclipse Temurin 25.
  • ✅ 在 Windows / macOS / Linux 上成功安装了 JDK 25.
  • ✅ 配置了 JAVA_HOME 和 PATH 环境变量。
  • ✅ 使用 java -version 命令验证了 JDK 安装。
  • ✅ 体验了 JShell 交互式编程工具。
  • ✅ 使用 javac 和 java 命令成功编译并运行了第一个 Java 程序。
  • ✅ 了解了 JDK 25 的简化语法（传统写法仍然是学习重点）。

6. 练习

  1. 环境自查：在终端中分别运行 java -version 和 javac -version，确认两条命令均正常输出且版本号显示为 25。如果失败，请回顾本章的环境变量配置部分。
  2. JShell 体验：启动 JShell，尝试以下几项操作，观察输出结果：
    • 定义一个整数变量并输出
    • 使用 Math.max() 和 Math.min() 方法比较两个数
    • 使用 Math.pow() 计算 2 的 10 次方
  3. 命令行编程（传统方式）：使用文本编辑器编写一个程序，分别输出你的姓名、年龄和所在城市。用 javac 编译并 java 运行。
  4. 命令行编程（简化方式，选做）：使用 JDK 25 的简化语法，编写一个程序输出 “你好，Java 25！”，并用 java 命令直接运行。

完成这些练习后，你将为下一章在 IntelliJ IDEA 中开发打下坚实基础。
