第一章：走进 Java 世界

Java 教程 · 2026-04-26 · 8 分钟阅读

欢迎来到 Java 编程的世界！无论你之前是否接触过编程，这都将是一段充满乐趣和挑战的旅程。

本章将带你了解 Java 的过去、现在与未来，帮助你建立起对 Java 的整体认知，为后续深入学习打下坚实基础。

1. Java 语言发展史

1.1 诞生：从 Oak 到 Java

故事要从 20 世纪 90 年代初说起。当时，Sun Microsystems 公司的工程师詹姆斯·高斯林（James Gosling）带领一个团队，希望为消费类电子产品（如电视机顶盒、微波炉等）开发一种新的编程语言。这种语言需要具备 跨平台 的能力，因为不同的家用电器采用不同的处理器。

于是，一种名为 Oak 的语言在 1991 年诞生了。高斯林非常喜欢他办公室窗外的橡树，便以此命名。然而，Oak 在发展初期并未在消费电子市场掀起波澜。

转机出现在互联网兴起之时。Sun 公司发现，Oak 语言的特性——安全、跨平台、动态网页交互——非常适合刚刚兴起的互联网应用。1995 年，Sun 公司正式将 Oak 更名为 Java，并提出了口号 “Write Once, Run Anywhere”（一次编写，到处运行）。

随着 Web 浏览器的普及，Java Applet（可在浏览器中运行的小程序）令 Java 迅速风靡全球，成为网络编程的首选语言。

1.2 Java 的成长里程碑

  • 1996 年：JDK 1.0 发布，标志着 Java 开发工具包正式面世。
  • 1998 年：Java 1.2 发布，引入了集合框架等。
  • 2004 年：Java 5.0 发布，引入了泛型、增强 for 循环、自动装箱/拆箱、枚举、可变参数等核心特性。
  • 2006 年：Sun 公司宣布开源 Java，开启了 OpenJDK 项目。
  • 2009 年：Oracle 公司收购 Sun，Java 从此进入 Oracle 时代。
  • 2014 年：Java 8（LTS）发布，带来了 Lambda 表达式、Stream API、新的日期时间 API 等。
  • 2017 年：Oracle 宣布新发布节奏，每 6 个月发布一个新版本，并设立 LTS（Long-Term Support）版本以保证长期稳定。
  • 2018 年：Java 11（LTS）发布，进一步增强安全性。
  • 2021 年：Java 17（LTS）发布，密封类正式加入，Switch 表达式转正。
  • 2023 年：Java 21（LTS）发布，虚拟线程（Virtual Threads）正式推出，极大提升了高并发程序的编写效率和吞吐量。
  • 2025 年 9 月 16 日：Java 25（LTS）发布，Oracle 官方宣布提供至少 8 年的长期支持，包含 18 项 JEP（JDK Enhancement Proposals）新功能[reference:1][reference:2][reference:3]。

本教程将基于 Java 25（JDK 25）进行讲解。

1.3 名字背后的故事

Java 的命名趣味十足。最初叫 Oak，因为一棵橡树；后来改名 Java，取自印度尼西亚的爪哇岛，那里以盛产咖啡闻名。众多 Java 技术中常出现咖啡元素，比如 JavaBeans（咖啡豆），所以看到咖啡标志时别惊讶，那就是 Java！

2. Java 的特点与优势

Java 之所以历经近 30 年仍位居编程语言排行榜前列，主要归功于以下几个显著优势。

2.1 跨平台性（核心优势）

Java 程序运行在 JVM（Java Virtual Machine，Java 虚拟机） 上。不同操作系统（Windows、Linux、macOS 等）都有对应的 JVM 实现。Java 源代码（.java 文件）被编译成字节码（.class 文件），字节码是 JVM 能够识别的"平台无关"指令，由 JVM 翻译成所在平台的机器码执行。

简单理解： 你只需写一份 Java 程序，在任何安装了 JVM 的设备上都能运行。

2.2 面向对象

Java 是一门纯粹的面向对象编程语言（OOP），支持封装、继承、多态三大特性，强制使用类（class）来组织代码。面向对象的思想更契合人类对现实世界的认知模型，使得大型软件的设计和维护变得更加容易。

2.3 自动内存管理（垃圾回收）

Java 引入了 垃圾回收器（Garbage Collector, GC），会自动扫描堆内存，识别不再被使用的对象并回收内存空间。在 JDK 25 中，默认使用高性能的 G1 GC，同时还提供 ZGC 和 Shenandoah GC 作为低延迟选择。

2.4 健壮性、安全性与高性能

Java 强化了编译时类型检查和运行时异常检查，并强制要求进行显式的异常处理（try-catch），同时也提供了安全管理器和加密体系（JCA/JCE）等多种安全机制。JVM 采用 JIT（Just-In-Time）即时编译技术，能将频繁执行的热点代码直接编译为本地机器码缓存起来，运行效率非常接近甚至超越 C++。

2.5 庞大的生态系统

Java 拥有全球最大的开发者社区之一，以及极其丰富的开源框架、类库和工具。无论你需要什么功能，几乎都能找到成熟的解决方案。这极大提升了开发效率。

3. Java 技术体系平台

  • Java SE（Java Standard Edition，标准版）：Java 的核心和基础。无论要开发什么类型的 Java 应用，都必须先掌握 Java SE。本教程的前半部分主要聚焦于 Java SE。

  • Jakarta EE（原 Java EE，企业版）：建立在 Java SE 之上，增加了大量服务器端开发 API，如 Servlet、JMS、WebSocket 等。最新稳定版本是 Jakarta EE 11[reference:4]。近年来，Spring Framework（尤其是 Spring Boot 4.x / Spring Cloud）已经成为 Java 企业开发的主流选择。

  • Java ME（Java Micro Edition，微型版）：专为资源受限的嵌入式设备设计，目前应用范围很小，初学者基本无需学习。

注意： Android 应用的底层使用 Java 语言，但采用的是 Android SDK 和 Dalvik/ART 虚拟机。学习 Java SE 是学习 Android 开发的必备基础。

4. Java 的应用领域与就业前景

4.1 应用领域

  1. 企业级应用开发：银行、保险、电商、政府等后台系统大多数使用 Java 开发，尤其是基于 Spring Boot/Spring Cloud 的微服务架构。

  2. 大数据与云计算：几乎所有大数据处理框架都是用 Java 或 JVM 语言（如 Scala）编写的，包括 Hadoop、Spark、Flink、Kafka 等。掌握 Java 是进入大数据领域的必备基础。

  3. Android 应用开发：Android 应用层开发主要使用 Java 或 Kotlin，许多 Android 框架和工具链都以 Java 为基础。

  4. 中间件和基础设施：很多重要的中间件和基础软件都是用 Java 构建的，如：Tomcat、Jetty（Web 服务器）、Elasticsearch（搜索引擎）、Netty（高性能网络框架）。

  5. 科学计算与游戏后台：Java 也可用于开发大型多人在线游戏的服务端和科学计算软件。

4.2 就业前景

Java 后端开发岗位的需求一直稳居前列，尤其是在一线互联网公司和传统企业数字化转型的过程中，Java 人才需求巨大。Java 软件开发工程师在 2026 年依然是高需求岗位，尤其在金融、保险等行业。初级岗位（1 ~ 3 年经验）年薪约 36 万 ~ 39 万人民币。

提示： 薪资受地域、企业规模、个人能力等多种因素影响，以上数据仅供参考。

5. JDK 版本演进与选择

5.1 JDK 是什么？

JDK（Java Development Kit） 是 Java 开发工具包，包含：

  • JRE（Java Runtime Environment）：Java 运行时环境，包括 JVM 和核心类库；
  • 开发工具：编译器（javac）、打包工具（jar）、调试器（jdb）、文档生成器（javadoc）等。

简单来说：用户只需要安装 JRE 来运行 Java 程序，而作为开发者的你需要安装 JDK 来编写和调试程序。

5.2 现代 LTS 版本速览

自 Java 9 起，Oracle 将发布周期调整为每 6 个月发布一个功能版本。LTS（Long-Term Support，长期支持） 版本会得到至少 8 年的更新与安全补丁。最新 LTS 版本为 JDK 25（2025 年 9 月发布），下一个 LTS 版本预计为 JDK 27（2027 年发布）。

LTS 版本 发布时间 主要特性
Java 8 2014.03 Lambda 表达式、Stream API、新日期时间 API
Java 11 2018.09 增强安全性、新 HTTP 客户端
Java 17 2021.09 密封类、Switch 表达式转正
Java 21 2023.09 虚拟线程正式推出
Java 25 2025.09 18 项 JEP 新特性，8 年以上长期支持

5.3 发行版选择

市面上有很多 OpenJDK 发行版，推荐：

  • Eclipse Temurin：由 Eclipse 基金会维护，免费、开源、TCK 认证，支持 JDK 25 LTS。
  • Oracle JDK：Oracle 官方版本，使用需遵守许可。
  • Amazon Corretto：亚马逊提供，免费且长期支持。
  • Azul Zulu：提供免费社区版。

本教程推荐使用 Eclipse Temurin 25（最新 LTS 版本），它稳定、免费，没有任何使用限制。

6 学习 Java 的方法与建议

6.1 零基础如何开始？

  1. 不要试图一次性掌握所有东西：编程是一门实践性极强的学科，先理解基本概念，再通过编码巩固。
  2. 多动手，多敲代码：每一道例题和练习都亲自敲一遍，学会调试和解决错误才是成长。
  3. 理解原理而非死记硬背：例如，理解对象在内存中如何存储，比记住怎么写一个类更有价值。
  4. 逐步构建知识体系：Java SE → 面向对象 → 常用类库 → 多线程 → 集合框架 → IO → 高级特性，按顺序学习，会自然形成体系。
  5. 使用正确的工具：尽快习惯使用 IntelliJ IDEA，提供的代码提示、调试和重构功能能极大提高效率。

6.2 遇到问题怎么办？

  • 利用搜索引擎：遇到错误信息，先拷贝到 Google 或百度中搜索。
  • 查阅官方文档：JDK 的 API 文档是最权威的参考资料。
  • 在社区提问：Stack Overflow、CSDN、SegmentFault 等是程序员的好帮手。
  • 加入学习社群：与同学交流讨论，互相促进。

6.3 保持耐心和热情

学习 Java 可能会遇到难以理解的抽象概念，但请不要气馁。只要坚持动手实践，你会发现 Java 世界的大门会逐渐为你打开。当你写出第一个可以运行的程序，或成功调试出一个 bug 时，那种成就感是无与伦比的。

最后，记住一句话：Talk is cheap, show me the code.

好了，让我们开始激动人心的 Java 学习之旅吧！下一章，我们将搭建开发环境，并运行起第一个 Java 程序。
